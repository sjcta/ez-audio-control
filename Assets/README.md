# App icon

`SAC-icon-source.png` is the AI-assisted project artwork selected for Ez Audio Control. `AppIcon.icns` contains the standard macOS icon sizes. The artwork uses a full-bleed gradient, white speaker, separator and “Ez Studio” wordmark.

`scripts/build-icon.sh` regenerates the ICNS from the PNG. The normal App build copies the checked-in ICNS without regenerating or changing the source artwork.

The menu bar uses SF Symbols provided by macOS at runtime. Those system symbol assets and the system feedback sound are not copied into this repository. AI-assisted artwork is identified as such; no third-party stock-art attribution is claimed.
